# Nand - a one-operator programming language

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

Nand is a structured programming language with only the "nand" operator. It is a fork of the [Nor](https://github.com/code4fukui/Nor) project.

## Demo
- Runtime on web: [Nand Playground](https://code4fukui.github.io/Nand/)
- Embedded in HTML: [Nand on web](https://code4fukui.github.io/Nand/nandweb.html)

## Features
- Single operator "nand"
- Variables, arrays, conditional statements, loops, and functions
- Command-line interface (CLI) for calculations
- Debugging tool: [nand2js](https://code4fukui.github.io/Nand/nand2js.html)

## Requirements
No additional requirements.

## Usage
The source file extension for Nand is ".nand", and the MIME type is "text/nand".

Example CLI usage:
```sh
deno -A https://code4fukui.github.io/Nand/cli.js examples/add.nand
```
